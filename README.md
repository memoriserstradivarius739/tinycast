## 🔧 Getting Started Guide

### Using the Launcher

1. Press **Option + Space** (default shortcut) to open the launcher
2. Start typing the name of an app (like "mail" or "notes")
3. Use **Up/Down arrows** to select the result
4. Press **Enter** to launch

### Setting Up Hotkeys

1. Click the tinycast icon in the menu bar
2. Choose **Preferences**
3. Go to the **Hotkeys** tab
4. Click the **+** button to add a new hotkey
5. Assign a key combination and choose an action

### Using Clipboard History

1. Copy anything (text, image, or link)
2. Press **Shift + Option + V** (default shortcut) to open clipboard history
3. Scroll through your recent copies
4. Click on an item or press Enter to paste it

## 🛠️ Troubleshooting

### tinycast Doesn't Open
- Make sure you dragged it to the **Applications** folder
- Try right-clicking the icon and selecting **Open** from the menu
- Check that your Mac meets the system requirements

### Hotkeys Don't Work
- Check that you granted Accessibility permission in **System Settings > Privacy & Security**
- Try restarting tinycast from the menu bar icon
- Make sure your hotkey isn't already used by another app

### Clipboard History Is Empty
- Ensure Input Monitoring permission is granted
- Check that you haven't cleared history in settings
- Try copying a new item and then opening history

### tinycast Is Slow
- Restart the application from the menu bar
- Clear your clipboard history in Preferences
- Make sure your macOS is up to date
